# Davinci Seven · Z-Image UI — v1.4.0 source snapshot

这是达芬七 Z-Image 一键出图包 v1.4.0 的可追踪源码快照。

本分支只收录 UI、风格配置、启动/诊断脚本和说明文件；发行包里的 `engine/`（约 48GB，含 ComfyUI、Python、模型和 LoRA）以及 `userdata/` 不上传 GitHub。完整包仍通过网盘分发。

## 使用范围

- Windows + NVIDIA/CUDA
- 8GB 显存是主要目标配置
- 双击 `启动.bat` 启动 UI
- 需要已有的 ComfyUI-Z-Image 引擎和模型文件

后续开发版本在 `master` 分支；当前仓库的开发 HEAD 已超过 v1.4.0。不要把这个分支当成完整整合包下载地址。
